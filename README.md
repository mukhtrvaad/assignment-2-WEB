# ECHOWAVE

ECHOWAVE is a music streaming website created for Front-End Development Assignment #2.

The project demonstrates the use of Flexbox and CSS Grid.

## Pages

- HOME — Navigation Bar and Flexbox Cards
- ALBUMS — Grid Areas Layout
- ARTISTS — Image Gallery
- DISCOVER — Flexbox and Grid Combined

## Technologies

- HTML
- CSS
- Flexbox
- CSS Grid
